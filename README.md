## Installation

Define the following permissions in your `src-tauri/capabilities/default.json`:

```bash
# Using npm
npm run tauri add audio-recorder-android

# Using pnpm
pnpm tauri add audio-recorder-android

# Using yarn
yarn tauri add audio-recorder-android

# Using bun
bun tauri add audio-recorder-android
```

## Usage Patterns

### 1. Handling Permissions and Starting

```typescript
import { record, checkPermission, requestPermission, OutputFormat, AudioEncoder } from 'tauri-plugin-audio-recorder-android-api';

const handleRecord = async (filePath: string) => {
  const check = await checkPermission();
  if (!check.isGranted) {
    const req = await requestPermission();
    if (!req.isGranted) return;
  }

  await record({
    fileName: filePath,
    format: OutputFormat.MPEG_4,
    encoder: AudioEncoder.AAC
  });
};
```

### 2. Monitoring Status and Visualizing

Poll `getStatus` to retrieve the latest `maxAmplitude` for animations:

```typescript
setInterval(async () => {
  const status = await getStatus();
  if (status.isRecording) {
    console.log("Current Amplitude:", status.maxAmplitude);
    console.log("Recording Path:", status.currentPath);
  }
}, 100);
```

### 3. Control Operations

```typescript
// Pause the session
await pause();

// Resume the session
await resume();

// Stop and get result
const result = await stop();
console.log("Saved to:", result.currentPath);
```

## API Reference

### Data Models

| Model | Properties |
| :--- | :--- |
| `RecordRequest` | `fileName: string`, `format?: OutputFormat`, `encoder?: AudioEncoder` |
| `RecorderStatusResponse` | `success: boolean`, `isRecording: boolean`, `currentPath?`, `maxAmplitude?`, `message?` |
| `GenericResponse` | `success: boolean`, `message?`, `isGranted?` |

### Exported Enums

* `OutputFormat`: MPEG_4 (2), AAC_ADTS (6), WEBM (9), etc.
* `AudioEncoder`: AAC (3), HE_AAC (4), OPUS (7), etc.

## Android Requirements

Ensure these entries are in your `AndroidManifest.xml` for Foreground Service functionality:

```xml
<manifest xmlns:android="http://schemas.android.com/apk/res/android">

    <!-- Permissions -->
    <uses-permission android:name="android.permission.RECORD_AUDIO" />
    <uses-permission android:name="android.permission.FOREGROUND_SERVICE" />
    <uses-permission android:name="android.permission.FOREGROUND_SERVICE_MICROPHONE" />

    <application>
        <!-- Service Integration -->
        <service 
            android:name="com.plugin.audio_recorder_android.AudioRecordService"
            android:foregroundServiceType="microphone"
            android:exported="false">
        </service>
    </application>
</manifest>
```

## Notes
* `Amplitude Tracking:` The `maxAmplitude` returns values up to `32767`, perfect for building real-time wave visualizers.
* `Desktop / iOS Support:` This plugin is specifically designed for Android. Desktop and iOS platforms are currently not supported.
